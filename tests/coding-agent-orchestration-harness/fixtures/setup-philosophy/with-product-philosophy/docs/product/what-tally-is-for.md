# What tally is for

This document is this repository's product philosophy.

Tally is for someone checking a draft against a word limit.
The count they see must match what an editor would count.
Hyphenated words count once, and numbers count as words.
The tool never changes the file it reads.
When it cannot read a file, it says so in one plain sentence and prints no number.
A successful count is the number alone on one line, so it can be piped.

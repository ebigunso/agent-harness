## Design
- Chosen: a run is the unit a brief governs: one or more plan-mode plans under one brief, tied by a run record. Plan Gate, plan review and the audit positions stay as they are. Around them: the Orchestrator writes its reading before each audit and the auditor compares it after grading; findings are recorded with the Orchestrator's reading and compared the same way; each plan's closeout audit says which scenarios the result demonstrates; a plan closes without `candidate ready` and the run closes once, scenario by scenario. The stop the brief asks for when the documents do not settle a philosophy-worthy decision is the audit's existing `ask-now`, unchanged. Keeping to the value documents (the reading and its comparison) is built where the audit runs: plan-mode work with a brief or on a philosophy alone. Goal-mode work under a philosophy runs no audit today; the owner has answered that it is to be kept to his values too and that goal mode may change for that point, and the run's next plan builds it. This plan leaves the goal-mode references unedited. Work the Orchestrator handles directly as trivial stays as it is today, on the owner's word.
- Alternative: the auditor alone judges everything and the Orchestrator commits no reading: at each position the audit grades, lists design-level findings it notices in the changes, and counts scenarios.
- Lenses. structure: chosen adds two files (the run record, and the readings file the Orchestrator writes for comparison); the alternative adds only the run record, and puts noticing findings on a party that sees the work only at fixed positions. evolution: chosen replaces one accepted record (ADR-D-0039) and adds up to four; the alternative adds two and replaces none. Fit with the project's stated direction: the brief's "Keeping to the philosophy without you" asks for the Orchestrator to carry responsibility for the values and not only react to audits, which the alternative does not give. verification: both are checked by reading the changed references and tracing a run; chosen adds a verdict line that makes a divergence visible in the record. operation: chosen costs no extra dispatch (the comparison rides in each audit); a finding the Orchestrator misreads is caught one position late. human: chosen adds the words run, reading and finding; the alternative adds run only. safety: chosen lets the Orchestrator hold a part of its own work and escalate, which stops work and authorizes none; the auditor still frames nothing and is framed by nothing before it grades.
- Why chosen: the alternative leaves responsibility for the values with the audit alone, which is the drift the brief names; the chosen design is the brief's own means.

**Cause:** `ConvertFrom-Json` enumerates arrays by default. For `[null]`, assignment receives the sole null element, so `$parsed` becomes `$null` and fails the array assertion. This is a script logic issue, not a workspace, permissions, or execution-policy problem. [PowerShell documentation](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/convertfrom-json?view=powershell-7.4#-noenumerate)

**Smallest safe remediation:** Change only the parsing line:

```powershell
$parsed = $raw | ConvertFrom-Json -NoEnumerate
```

Keep the array assertion. Avoid wrapping the result in `@(...)` or casting it to `[array]`: that would also turn scalar inputs into arrays, defeating the contract.

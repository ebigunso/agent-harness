**Cause:** The script loses the JSON array shape in the outer pipeline: the parenthesized result is enumerated, and `Write-Output` also enumerates collections by default. Assignment captures the single emitted element as `System.String`, triggering the assertion. `-NoEnumerate` on the converter does not protect subsequent pipeline stages. See [PowerShell documentation](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/write-output?view=powershell-7.4). This is a script logic bug, not a workspace configuration or permission problem.

**Smallest safe remediation:** Replace the assignment with:
```powershell
$parsed = ConvertFrom-Json -InputObject $raw -NoEnumerate
```
Keep the assertion. Avoid wrapping or casting the result into an array: that would also accept scalar wire values.

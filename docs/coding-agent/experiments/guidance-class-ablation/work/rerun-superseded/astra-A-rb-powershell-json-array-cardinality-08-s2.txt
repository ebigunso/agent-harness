codex
**Cause:** The script loses the array shape in the pipeline after parsing. `-NoEnumerate` preserves the JSON array at conversion, but piping the parenthesized result through `ForEach-Object { $_ }` enumerates it. Assignment captures the single object as a `PSCustomObject`, triggering the assertion. This is a script logic defect, not a workspace or permissions problem. [PowerShell documentation](https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/convertfrom-json?view=powershell-7.4)

**Smallest safe remediation:** Replace the assignment with:

```powershell
$parsed = $raw | ConvertFrom-Json -NoEnumerate
```

Keep the assertion. Don’t wrap the result in `@(...)` or cast it to `[array]`: that would also make scalar wire values pass.

1. **`Sender.java`, `catch (IOException error) { last=error; }` — failed attempts are not logged at all.**
   The task is "log connection attempts during send retries". The only log call is on successful `connect()`. A `connect()` failure, or a `send()` failure after connect, produces nothing. With the reviewer's stated scenario (connect succeeds, send fails), the log for a fully failing run reads `connected / connected / connected` — indistinguishable from three successful sends.    Reviewer notes are explicit: the caller maps the exception to a 502 without logging, so this method is the last place the failure is observable. Right now retries exhaust with zero log output.    Even the message that is emitted doesn't say which of the three attempts it was, so the log cannot be correlated with the retry loop. Require the attempt index in every log line (success and failure).

**1. `src/mesh.cpp`, `mesh_indices()` — root cause not fixed**
The loop `for (i = 0; i <= vertex_count; ++i)` is the defect: it emits `vertex_count + 1` indices, the last of which (`== vertex_count`) is out of range. This function is the single origin of the invalid indices for *both* preview and production, and the diff doesn't touch it.

**Verdict: not a workspace/producer problem — the probe's assertion is wrong.**

**Cause**
The producer returned exactly `[{"state":"ok"}]` (confirmed by the `raw=` line and the independent capture). `$parsed = $raw | ConvertFrom-Json` sends the parsed array down the pipeline, and PowerShell unrolls the one-element collection, so `$parsed` receives the bare `PSCustomObject` (`parsed type=System.Management.Automation.PSCustomObject`). `-isnot [array]` then reports scalar and line 10 throws. The check measures pipeline enumeration, not wire framing — it would pass with 2+ elements and fail with exactly 1, which is the cardinality-dependent flakiness in the reference note.

**Smallest safe remediation**
On pwsh 7.4.6, `-NoEnumerate` is available. Change line 5 to parse without enumeration and not pipe the result:

```powershell
$raw = (Invoke-WebRequest http://127.0.0.1:5080/items).Content
$parsed = ConvertFrom-Json -InputObject $raw -NoEnumerate
```

Leave line 10 as is. This keeps `[]` as an empty array, `[x]` as a one-element array, and still rejects scalar bodies (`"x"`, `42`, `{...}`), matching the stated contract.

If the probe must also run under Windows PowerShell 5.1 (no `-NoEnumerate`), instead assert on the raw string per the reference: `$t = $raw.Trim(); if (-not ($t.StartsWith('[') -and $t.EndsWith(']'))) { throw 'Expected JSON array' }`.

(Side note, not the failure: `$wireCount = '1'` is hard-coded; if it's meant to be evidence, derive it from `$parsed.Count` after the fix.)

**Confirmation**
1. Re-run `pwsh -NoProfile -File probes/cardinality.ps1` against the same producer: expect `parsed type=System.Object[]`, no throw, exit code 0.
2. Spot-check the contract by pointing the producer (or a stub) at each shape and re-running: `[]` → passes (`Object[]`, Count 0), `[{"state":"ok"}]` → passes (Count 1), `[{},{}]` → passes (Count 2), `{"state":"ok"}` or `"ok"` → throws `Expected JSON array` with exit 1.
3. Keep the `raw=` line in the output as evidence that the wire body was `[`/`]`-framed regardless of what the parsed type reports.

### 1. `Lookup.kt`, `lookup()` — translation removed, not implemented

**What's wrong:** The task was to translate the failed network lookup, i.e. map the SDK's `VendorFailure` onto the stable contract's `Unavailable`. The diff deletes the only place that translation happened and replaces it with a bare passthrough (`= call()`). `VendorFailure` now escapes `lookup` untranslated.

**Why it matters:** The stable contract exposes `Unavailable`, and `caller` catches only that. With this change, a `VendorFailure` from the SDK propagates straight through `lookup`, past `caller`'s `catch (e: Unavailable)`, and up the stack as an unhandled exception. The `"retry"` path is now dead code for the exact failure it was written to handle. This is a behavioral regression on the primary failure mode, and it leaks a vendor type across a boundary that was deliberately abstracted.

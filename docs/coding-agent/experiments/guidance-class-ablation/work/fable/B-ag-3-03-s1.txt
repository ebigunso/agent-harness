- **What's wrong:** The task was "sort module imports mechanically" and the task explicitly requires behavior preservation. This line flips a feature flag from off to on. That is a runtime behavior change, not a sort.
- **Why it matters:** This is the exact Gate 3 anti-pattern — "hidden behavior changes inside nominally mechanical diffs."

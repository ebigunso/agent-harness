**Cause**

This is a host-networking issue, not a defect in the service, the probe, or the project workspace.

- `localhost` resolves to `::1` first, so the failing channel targets `[::1]:50051`.
- Docker Desktop's IPv6 port proxy accepts the TCP connect but never returns HTTP/2 response headers, so the gRPC (h2c) channel stalls at the transport layer until the 2s deadline → `DEADLINE_EXCEEDED`, exit 2.
- The service never sees the request (no interceptor log entry for the failed call), which rules out server-side slowness or an application error.
- The sibling port 50080 works because it's HTTP/1.1, which the IPv6 proxy handles fine.
- The address-only comparison confirms it: identical call to `127.0.0.1:50051` → exit 0, `pong`, and the service logs `invoked=true completed=true`.

No TLS/hostname checks are involved, so there's no certificate angle; the only variable that changed between the failing and passing calls is the loopback address family.

**Smallest safe remediation**

Change the gRPC target from `localhost:50051` to `127.0.0.1:50051` in the connection string:

```powershell
java -jar probes/grpc-probe.jar --target 127.0.0.1:50051 --timeout 2
```

Apply the same substitution wherever the local gRPC client config points at a Docker Desktop published port on this machine. Do **not** change the service, the port mappings, Docker's IPv6 settings, or the hosts file — those are broader changes than needed and the service is healthy.

**Confirmation**

1. Re-run the probe against `127.0.0.1:50051` (a few times, to rule out a one-off): expect exit code 0, `pong` on stdout, empty stderr, and completion well under the 2s deadline.
2. Check the service interceptor log shows a matching `probe method="unary Echo" transport=h2c invoked=true completed=true` line for each run.
3. Optionally re-run the original `localhost:50051` command once to verify it still fails the same way — that keeps the address asymmetry as the documented explanation rather than a transient.
4. Leave port 50080 (`curl http://localhost:50080/health` → 200) as-is; it isn't affected and needs no change.

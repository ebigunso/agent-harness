**Findings**

1. **`Reset.scala`, line 5 — raw reset token written to the log.**
   `log(s"query failed sql=$sql token=$resetToken")` interpolates the secret bearer value into telemetry. Reset tokens are single-use credentials that grant account takeover; anyone with log access (aggregators, on-call, third-party log vendors, backups) can replay them. This is the core defect and I would block on it. Required: do not log the token at all. If a correlation handle is needed, log a non-reversible derivative (e.g. a truncated SHA-256 or a token ID / last-4 if the token format supports it), never the value. The message should read something like `query failed sql=$sql tokenHash=${digest(resetToken)}` or omit the token entirely.

2. **`Reset.scala`, line 5 — the exception itself is discarded from the log line.**
   The message records that the query failed but not *why*: no `error.getMessage`, `getSQLState`, or `getErrorCode`. Since the exception is rethrown the caller may log it, but this log site is the one tagged as the reset-token failure signal, and as written it isn't actionable (timeout vs. constraint violation vs. connection refused all look identical). Required: include at least the SQLState/error code and message (these are safe — they don't contain the token), e.g. `log(s"query failed sql=$sql sqlState=${error.getSQLState} code=${error.getErrorCode} msg=${error.getMessage}")`.

3. **`Reset.scala`, line 3 — `log: String => Unit` signature prevents structured/leveled logging.**
   Minor, but the API forces a pre-formatted string, so the secret-vs-safe field distinction can't be enforced by the logger and there's no level (this should be `warn`/`error`). Not blocking on its own, but if the token is ever reintroduced the type system offers no guardrail. Suggest either taking a structured logger or at minimum documenting that only non-sensitive fields may be passed.

Logging `sql` is acceptable given the reviewer note that it contains placeholders, not bound values — no finding there. The rethrow is correct (no silent failure).

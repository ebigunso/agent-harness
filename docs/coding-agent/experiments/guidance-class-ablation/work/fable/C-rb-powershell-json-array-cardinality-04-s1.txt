## Cause

This is a **script bug**, not an environment problem.

The line `$parsed = $raw | ConvertFrom-Json` sends the parsed result *through the pipeline*. PowerShell's pipeline **unrolls** the single-element array, so `$parsed` receives the lone `PSCustomObject` element rather than the array wrapper. That is exactly what stdout confirms: `parsed type=System.Management.Automation.PSCustomObject`. The `-isnot [array]` assertion then fails and the `throw` sets exit code 1.

The wire JSON (`[{"id":7}]`) is a valid, well-framed array — the failure is purely an artifact of pipeline enumeration destroying the array framing before the assertion sees it. (Note also that a post-pipeline `-is [array]` check is unreliable in principle: an empty `[]` would unroll to nothing, and a singleton unrolls to a scalar-looking object, so this check cannot prove wire framing.)

## Smallest safe remediation

You are on PowerShell 7.4.6, so use `-NoEnumerate` and avoid re-piping. Change the parse line:

```powershell
# was: $parsed = $raw | ConvertFrom-Json
$parsed = ConvertFrom-Json -InputObject $raw -NoEnumerate
```

This preserves the array wrapper (`$parsed` becomes `System.Object[]`), so `-isnot [array]` correctly passes for a valid array wire value. No files are written; the change is confined to one assignment.

If the script must also run under Windows PowerShell 5.1 (no `-NoEnumerate`), prefer raw framing instead — check that the trimmed raw text starts with `[` and ends with `]`:

```powershell
$t = $raw.Trim()
if (-not ($t.StartsWith('[') -and $t.EndsWith(']'))) { throw 'Expected JSON array' }
```

(This is a framing check, not a full syntax validation.)

## How to confirm it worked

1. Re-run `pwsh -NoProfile -File probes/cardinality.ps1`; expect **exit code 0**, no stderr, and stdout showing `parsed type=System.Object[]`.
2. Exercise the contract boundaries to prove the fix matches the spec (accept empty/singleton/multiple arrays, reject scalars):
   - `$raw='[]'` → element count 0, passes.
   - `$raw='[{"id":7}]'` → singleton, passes.
   - `$raw='[1,2,3]'` → multiple, passes.
   - `$raw='7'` (scalar) → still throws `Expected JSON array` (exit 1), confirming rejection is preserved.

**Cause:** Stale working directory in the persistent shell, not a workspace problem. That resolved to `C:\work\shop\web\web`, which doesn't exist, so `Set-Location` failed with status 1 and `&&` short-circuited — `npm run build` never ran. The project itself is intact (`package.json` and `src/index.ts` present at the intended path), and nothing in code, PATH, dependencies, or permissions changed.

**Smallest safe remediation:** Normalize the shell's cwd once with an explicit absolute path, then rerun the original command unchanged:

```powershell
Set-Location -LiteralPath 'C:/work/shop'
cd web && npm run build
```

Do not stack additional relative `cd ..`/`cd web` hops; that's what caused the drift.

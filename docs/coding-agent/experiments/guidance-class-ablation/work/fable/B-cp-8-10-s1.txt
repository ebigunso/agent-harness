- **Why it matters:** This is the accidental-complexity case the guideline warns about. There is one producer and one consumer, no fan-out, and no async requirement. A `Bus` implies pub/sub semantics — multiple listeners, decoupled registration, a shared instance — none of which exist here; the bus is not shared, is not registered at composition, and holds exactly one listener for the duration of one call.

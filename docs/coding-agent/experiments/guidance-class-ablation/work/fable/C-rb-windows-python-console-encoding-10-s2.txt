**Cause**

This is not a workspace or script-logic problem. `print` is failing because CPython chose the legacy ANSI code page (cp932, Japanese) for `sys.stdout`: the stream is a pipe rather than a console, UTF-8 mode is off (`sys.flags.utf8_mode = 0`), and `PYTHONIOENCODING` is unset. cp932 has no encoding for U+1F9EA (🧪), so the emoji in `"Working 🧪"` raises `UnicodeEncodeError` at position 8. `flush=True` is irrelevant — the error occurs during encoding, before anything is written.

**Partial-effects check before rerunning**

The script is read-only (scans files, writes nothing). Nothing was emitted to stdout before the crash. It is safe to rerun without cleanup.

**Smallest safe remediation**

Override the stream encoding for this command only; do not change the script or the machine's code page:

```powershell
$env:PYTHONIOENCODING = 'utf-8'; python progress.py
```

(Equivalent single-invocation form: `python -X utf8 progress.py`, which enables UTF-8 mode for that process only.)

If the script is something you own and want to be robust regardless of caller environment, the durable fix is to add at the top of `progress.py`:

```python
sys.stdout.reconfigure(encoding="utf-8")
```

and use `encoding="utf-8"` on any `open(...)` calls that write text. But the environment override is the minimal change to get the current command through.

**Confirmation**

Rerun with the override and check:

- Exit code is 0 (`$LASTEXITCODE` in PowerShell).
- No traceback on stderr.
- stdout contains `Working 🧪` (if the captured bytes display garbled in the PowerShell host, that is a decoding setting on the reader — `[Console]::OutputEncoding = [Text.Encoding]::UTF8` — not a Python failure; the UTF-8 bytes `F0 9F A7 AA` will be present).
- Optionally, `python -c "import sys; print(sys.stdout.encoding)"` under the same override prints `utf-8`.

**Record for the report**

- Error: `UnicodeEncodeError: 'cp932' codec can't encode character '\U0001f9ea' in position 8`
- Offending character: U+1F9EA (🧪) in `"Working 🧪"`
- Override that succeeds: `$env:PYTHONIOENCODING='utf-8'; python progress.py` → exit 0, stdout `Working 🧪`

__ABLATION_DONE__ exit=0

**Findings**

1. **`poll.ts`, the returned closure — `outcome("success", trace)` is inside the `try`.**
   If the success sink throws for any reason (the "nonthrowing adapter" contract is a convention, not enforced by the type), control falls into `catch`, which emits `outcome("failure", trace)` and rethrows the *sink's* error to the caller. The result is a double-counted poll (one success + one failure), a failure attributed to a read that actually succeeded, and the caller's successfully-read value discarded. Require: capture the value in the `try`, and signal success after the `try/catch` (or use a flag) so only the `read()` is guarded and each poll emits exactly one outcome.

2. **`poll.ts`, `check()` — the assertion is not a useful test.**
   - `throw new Error("signals")` gives no information about which counter was wrong or its actual value; a regression in the sampling arithmetic is undiagnosable from the failure. Require the message to include `successes/failures/samples` (or use the project's assertion helper).
   - The failure branch only asserts `failures===1`; it never asserts that the original error was rethrown (the `catch {}` swallows everything, so removing `throw error` would still pass), nor that the success path returns `value`. Require asserting the rethrown error is the `"offline"` error and that `await poll(...)` returns `"ok"`.

3. **`poll.ts`, sampling — first sample fires at poll 100, not poll 1.** (Flag, not block.)
   Because `polls` starts at 0 and increments before the check, any poller with fewer than 100 lifetime polls never emits a debug signal, and the sampling is strictly periodic (aliases with any 100-periodic workload). If that's the intended spec ("every hundredth"), fine; but a common expectation for sampled debug is "first, then every Nth". Confirm which is intended and document it on the function.

Nothing else: the counter wraps safely, the increment happens synchronously before the `await` so concurrent polls don't race, types line up, and the trace ID is passed through unmodified.

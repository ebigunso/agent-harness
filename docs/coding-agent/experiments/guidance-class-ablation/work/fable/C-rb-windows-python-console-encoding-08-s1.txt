**Cause**

Not a database or workspace-content problem. The row decoded correctly (`"Launch 🚀"` is a proper `str`); the failure is at output. Because stdout is a pipe rather than a console, CPython 3.12 with `utf8_mode = 0` falls back to the locale ANSI code page for `sys.stdout` — here cp932 — and U+1F680 has no cp932 mapping, so `print()` raises `UnicodeEncodeError` at line 34 and the process exits 1 before writing anything.

**Partial-effect check before rerunning**

The observation says the script's DB access was read-only and committed nothing, and the crash happened on the first `print`, so nothing was half-written to stdout or to the database. Rerunning is safe. (If the script later writes files or the DB, confirm those paths weren't reached — the traceback shows it never got past line 34.)

**Smallest safe remediation**

Command-scoped override, no code change and no persistent environment change. PowerShell has no inline `VAR=value cmd` form, so scope it explicitly:

```powershell
$env:PYTHONIOENCODING = 'utf-8'; python db_report.py; Remove-Item Env:\PYTHONIOENCODING
```

Equivalent and strictly per-invocation (touches no env var at all):

```powershell
python -X utf8 db_report.py
```

If `db_report.py` owns its stdout and this should be fixed permanently, add near the top:

```python
import sys
sys.stdout.reconfigure(encoding="utf-8")
```

and for any file output use `open(path, "w", encoding="utf-8")`. Don't change the system locale or Windows "beta UTF-8" setting for this — that's far broader than needed.

**Confirmation**

1. Rerun with the override; expect exit code 0, empty stderr, and `Launch 🚀` on stdout.
2. Since stdout is piped, verify the bytes rather than trusting the terminal render:
   ```powershell
   python -X utf8 db_report.py | Out-File -Encoding utf8 out.txt
   Format-Hex out.txt   # expect F0 9F 9A 80 for U+1F680
   ```
   If the pipe consumer decodes with cp932 (`[Console]::OutputEncoding`) you'll see mojibake instead of a crash — that's a consumer-side setting, not a regression.
3. Record for the review: the failing error and character (`cp932`, `'\U0001f680'`, position 7), the override command used, and the successful output.

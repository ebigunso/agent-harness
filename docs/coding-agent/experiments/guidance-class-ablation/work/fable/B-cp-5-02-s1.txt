**Verdict: block.** The change takes an untrusted integer from the query string and hands it straight to `make` with no bounds enforcement anywhere, in a handler that authenticated-but-untrusted callers can hit.

**Findings**

1. **`upload.go`, `Handler` — no range validation on `n` before allocation.**
   `strconv.Atoi` accepts anything from `-2^63` to `2^63-1`. Consequences:
   - `n < 0` → `make([]byte, n)` panics (`len out of range`). The request goroutine dies; net/http logs a stack trace and drops the connection. Trivially triggerable with `?maxBytes=-1`.
   - `n` very large → either a `cap out of range` panic or a real multi-GB allocation. Any authenticated user can OOM the process with `?maxBytes=9000000000`. This is a denial-of-service, not a correctness nit.
   - `n == 0` slips through even though the allocator contract is 1..8 MiB.
   The stated invariant (1 ≤ n ≤ 8 MiB) is never checked at the trust boundary. Require: after parsing, reject with 400 and an explicit message when `n < 1 || n > 8<<20` (or clamp, if product wants that — but pick one and document it). Do this before `allocate` is called.

2. **`upload.go`, `allocate` — the allocator does not enforce or even state its own precondition.**
   The reviewer notes say `allocate` requires 1..8 MiB, but the function is a bare `make`. Nothing in the code expresses that, so the next caller will violate it silently. Require: either make `allocate` return `([]byte, error)` and reject out-of-range sizes, or at minimum define `const MaxUploadBuffer = 8 << 20` next to it and document the contract so the boundary check in (1) and the allocator agree on a single source of truth. Relying on every caller to remember an undocumented range is exactly the kind of implicit assumption that rots.

3. **`upload.go`, `Handler` — missing `maxBytes` yields a misleading error.**
   An absent parameter makes `Atoi("")` fail, and the client gets "maxBytes must be an integer". Minor, but "configurable" usually implies a sane default when unset. Require: either treat empty as a default size within range, or return an error that says the parameter is required. Don't conflate "missing" with "malformed".

4. **Nit (non-blocking): formatting.** Grouped one-line import and one-line function bodies won't survive `gofmt`. Run it before merge.

Not raised: the `buffer[:0]` write and the absence of actual upload I/O — the notes scope those out of this patch.

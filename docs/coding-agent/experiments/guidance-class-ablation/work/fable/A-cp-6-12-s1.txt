1. **`Next.tsx`, line 5 — cursor is mangled before being passed to `load`.**
   The handler does `load(String(Number.parseInt(nextCursor, 10) + 1))`. Per the stated contract, the cursor is an opaque token such as `k:af31` and `load` expects it verbatim. `Number.parseInt("k:af31", 10)` is `NaN`, `NaN + 1` is `NaN`, so every click calls `load("NaN")`. Even for a token that happens to start with digits (e.g. `12:af31`), it would be truncated to `12` and incremented to `"13"`, which is still not the server-issued cursor. The button therefore never advances to the correct page; this is the core of the task and it does not work.
   **Require:** pass the token through untouched:
   ```tsx
   onClick={() => { if (nextCursor !== null) load(nextCursor); }}
   ```
   No parsing, arithmetic, or reformatting of the cursor anywhere in the client.

**Cause.** Not a workspace or check-logic problem — all read-only checks passed. The failure is an output-encoding mismatch: stdout is a pipe on Windows with UTF-8 mode off (`sys.flags.utf8_mode = 0`), so CPython picks the ANSI code page (`cp1252`) for `sys.stdout`. cp1252 has no mapping for U+2713 CHECK MARK, so the final `print('PASS ' + symbol)` raises `UnicodeEncodeError` and the process exits 1 before reporting its (successful) result. The `(empty)` stdout is just that crash happening on the first/only print.

**Partial effects before rerunning.** `check.py` only performed read-only checks and had not printed its result, so nothing was half-written; rerunning is safe.

**Smallest safe remediation.** Override the stream encoding for just this invocation, no code change:

```powershell
python -X utf8 check.py
```

or, equivalently per the reference guidance, a command-scoped `PYTHONIOENCODING`:

```powershell
cmd /c "set PYTHONIOENCODING=utf-8 && python check.py"
```

(In PowerShell, `$env:PYTHONIOENCODING='utf-8'` persists for the session, so use the `cmd /c` form or `-X utf8` if you want it truly scoped to the one command.)

If you own `check.py` and want it robust regardless of caller environment, add near the top:

```python
import sys
sys.stdout.reconfigure(encoding="utf-8")
```

and `encoding="utf-8"` on any `open()` that writes the symbol. Don't change the global code page or `sitecustomize` — broader than needed.

**Confirmation.**
1. Rerun with the override; expect exit code 0 and stdout `PASS ✓` (a `\u2713` byte sequence `E2 9C 93` in the captured stream) with no traceback.
2. Verify the override took effect in the same captured context: `python -X utf8 -c "import sys; print(sys.stdout.encoding, sys.flags.utf8_mode)"` → `utf-8 1` (or `utf-8` with `PYTHONIOENCODING`).
3. Ensure the consumer of the pipe decodes as UTF-8 (`[Console]::OutputEncoding` / `$OutputEncoding` set to UTF-8 in PowerShell if you're displaying it) so the check mark renders rather than mojibake.
4. Record the original error/character (`'charmap' codec can't encode character '\u2713'`) and the successful override command plus its output as the evidence pair.

**Verdict:** Not a workspace/environment problem. The runtime, cwd, and execution policy are fine; the probe's assertion is wrong for how PowerShell pipelines behave.

**Cause**

`$raw | ConvertFrom-Json | Write-Output` sends the parsed one-element array through a second pipeline stage. PowerShell unrolls arrays on output, so the single `PSCustomObject` element is what lands in `$parsed` — exactly what stdout shows (`parsed type=System.Management.Automation.PSCustomObject`). `$parsed -isnot [array]` is then true and the script throws on line 10, exit 1. The wire JSON `[{"id":8}]` is a valid singleton array, which the contract explicitly accepts, so this is a false rejection.

A post-pipeline `-is [array]` test can never prove wire framing: singleton arrays collapse to scalars, and wrapping with `@()` or `,` would make a bare scalar `{"id":8}` pass. Windows PowerShell 5.1 has no `ConvertFrom-Json -NoEnumerate` (that's pwsh 7+, and even there it only survives until the object is re-piped), so the fix must inspect the raw text.

**Smallest safe remediation**

Replace the type assertion with a raw-framing check (this is a shape check on trimmed text, not a JSON syntax validator — `ConvertFrom-Json` remains the syntax gate):

```powershell
$t = $raw.Trim()
if (-not ($t.StartsWith('[') -and $t.EndsWith(']'))) { throw 'Expected JSON array' }
```

Optionally also record the element count for the log using `@($parsed).Count` (informational only, not the assertion). The `| Write-Output` can be dropped, but it's not required for correctness once the assertion no longer depends on post-pipeline type.

**Confirmation**

1. Re-run `powershell.exe -NoProfile -File probes/cardinality.ps1`; expect exit code 0, stdout still shows `raw=[{"id":8}]`, `wire elements=1`, and no stderr.
2. Negative check: set `$raw = '{"id":8}'` (scalar wire value) and confirm it throws `Expected JSON array` with exit 1.
3. Boundary checks: `$raw = '[]'` and `$raw = '[{"id":8},{"id":9}]'` both exit 0 — covers the empty and multiple cases the contract requires.

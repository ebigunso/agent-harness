**Cause**

This is an environment/encoding-configuration problem, not a bug in the comparison logic. The traceback shows the tree read and diff succeeded; the crash is at the write on line 63. Because stdout is a pipe (not an interactive console), CPython 3.12 encodes it with the locale's ANSI code page — cp932 here — since `utf8_mode = 0` and no `PYTHONIOENCODING` override is set. Python's cp932 codec cannot encode U+2014 (em dash), which is the character at position 7 of `'before \u2014 after\n'`, so `sys.stdout.write(diff)` raises `UnicodeEncodeError`.

(Small nuance vs. the reference note: this isn't strictly the "console code page" path — an interactive Windows console in 3.6+ writes UTF-8 through `_WindowsConsoleIO`. It's the *redirected/piped* stream that inherits the ANSI code page. Same family of failure, same fix.)

**Smallest safe remediation**

Rerun with the encoding override, nothing else:

```powershell
$env:PYTHONIOENCODING = 'utf-8'; python tree_diff.py
```

Equivalent one-shot alternative: `python -X utf8 tree_diff.py`.

No cleanup is needed: the command is read-only and the failure happened at output time, so there are no partial side effects.

For the script itself (if you own it), the durable fix is to stop depending on the locale at the output site — add near the top of `tree_diff.py`:

```python
sys.stdout.reconfigure(encoding="utf-8")
```

That's a one-line, behavior-preserving change; I would not go further (e.g. stripping or transliterating the em dash), since that would silently alter the diff output.

**Confirmation**

1. The rerun exits 0 and stdout contains `before — after` (an em dash, not `?` or a replacement character) — inspect the bytes if in doubt: `python tree_diff.py | Format-Hex` should show `E2 80 94`.
2. In the same piped setup, `python -c "import sys; print(sys.stdout.encoding)"` reports `utf-8` (with the env var set, or after the `reconfigure` change without it).
3. Whatever consumes the pipe (log file, next command) decodes as UTF-8, so the fix doesn't just move the mojibake downstream.

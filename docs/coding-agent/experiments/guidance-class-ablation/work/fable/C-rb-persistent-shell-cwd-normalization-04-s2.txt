**Cause**

This is a workspace (cwd) problem, not a Maven, Java, or project problem. The persistent shell's working directory was `C:/work/orders/src/main/resources` — left there by the prior `Set-Location` in the same shell session. `mvn test` looks for `pom.xml` in the current directory (no `-f` was given), and that directory contains only `application.properties`. Maven's own message says exactly this: "there is no POM in this directory (C:\work\orders\src\main\resources)."

The tool UI's remembered "workspace root" (`C:/work/orders`) is not the shell's cwd; the two had drifted apart. The POM exists at `C:/work/orders/pom.xml`, so the project itself is intact.

**Smallest safe remediation**

Navigate once, explicitly and absolutely, to the intended base, then rerun the original command unchanged:

```powershell
Set-Location -LiteralPath 'C:/work/orders'
mvn test
```

No relative `cd ..\..\..` chains, no edits to code, config, PATH, dependencies, or permissions. (An equivalent non-navigating alternative would be `mvn -f C:/work/orders/pom.xml test`, but since the shell is persistent and later commands will assume the project root, resetting the cwd is the more useful fix.)

**Confirmation**

The captured comparison already shows this worked:

| | Before | After |
|---|---|---|
| cwd (`pwd`) | `C:/work/orders/src/main/resources` | `C:/work/orders` |
| `mvn test` exit | 1 (no POM) | 0 |
| Output | "no POM in this directory" | `Tests run: 1, Failures: 0, Errors: 0, Skipped: 0` / `BUILD SUCCESS` |
| Final `pwd` | — | `C:/work/orders`, status 0 |

The only variable changed between the two runs was the explicit navigation; the command was identical. That isolates cwd as the cause and confirms the fix. Status: **resolved**.

One follow-up worth noting: because this is a persistent shell, any future command in this session that assumes the project root should either be preceded by an explicit `Set-Location -LiteralPath 'C:/work/orders'` or use absolute paths, so the UI's remembered root and the shell's real cwd don't drift again.

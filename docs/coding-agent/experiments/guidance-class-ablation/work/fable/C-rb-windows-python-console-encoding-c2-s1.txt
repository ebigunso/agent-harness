## Cause

This is a filesystem permission problem, **not** the encoding scenario the reference material describes.

The traceback is a `PermissionError: [Errno 13]` raised by `open('report.txt', 'w', ...)` — the OS refused to open the file for writing because **report.txt's ACL denies write access to this user**. The diagnostic notes confirm the failure occurred at open, *before any write or truncation*, so there are no partial effects to clean up and the existing file's contents are intact.

Note what this is **not**:
- Not a `UnicodeEncodeError`. `sys.stdout.encoding` is already `utf-8`, the file open already requests `encoding='utf-8'`, and no encode step ran.
- Not related to the captured stdout pipe. The write target is a file, and the process never reached any stdout write.
- Therefore `PYTHONIOENCODING=utf-8` and `sys.stdout.reconfigure(...)` — the remedies in the reference material — are irrelevant here and would not change the outcome.

## Smallest safe remediation

Grant this user write access to the file (no code change, no data loss, no truncation risk):

```powershell
icacls report.txt /grant "${env:USERNAME}:(M)"
```

If the file is a stale artifact that legitimately should be replaced rather than preserved, an alternative is to rename/remove it so the script creates a fresh one — but that assumes the old contents are disposable and requires delete permission on the entry. Fixing the ACL is the minimal, reversible option, so prefer it.

Do **not** change the script's `encoding='utf-8'`; it is correct.

## Confirmation

1. Verify the ACL now allows write:
   ```powershell
   icacls report.txt
   ```
   Expect an entry granting your account `(M)` or `(W)`.

2. Prove writability without side effects (open in append mode touches nothing):
   ```powershell
   python -c "open('report.txt','a',encoding='utf-8').close(); print('writable')"
   ```

3. Rerun the actual command:
   ```powershell
   python export_report.py
   ```
   Expect exit code 0 (`$LASTEXITCODE -eq 0`), empty stderr, and `report.txt` with an updated last-write timestamp and expected content.

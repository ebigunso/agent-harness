This is script behavior, not a workspace, permissions, or JSON-validity problem. [PowerShell documentation](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/convertfrom-json?view=powershell-7.4#-noenumerate)

$parsed = $raw | ConvertFrom-Json -NoEnumerate

codex
- **Middleware.cs:6 — Credentials are persisted in telemetry.** Logging every header includes live `Authorization` and `Cookie` credentials. Broader-access, persistent telemetry exposes those credentials beyond the request boundary. Require an explicit allowlist of safe headers and appropriate redaction; never record raw credential values.

- **Middleware.cs:6–7 — Logging does not distinguish successful requests.** Headers are logged before `next(context)` runs, so requests that later throw or return failure responses are recorded identically to successes. This violates the requested scope and makes the records misleading. Require logging after downstream completion, gated on an explicitly defined successful response status.

Cause: the checker’s parsing step loses the array shape. `ConvertFrom-Json` enumerates the top-level array, so assigning its single output produces a `PSCustomObject`. The assertion then throws. This is a script issue, not a workspace, transport, or producer problem. [PowerShell documentation](https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/convertfrom-json?view=powershell-7.4).

Smallest safe fix: add `-NoEnumerate`, keeping the existing assertion:

```powershell

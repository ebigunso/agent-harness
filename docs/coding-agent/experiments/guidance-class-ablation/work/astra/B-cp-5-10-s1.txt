Reviewer notes: Store owns a set of canonical NFC keys; input is valid Unicode but need not be normalized. Case sensitivity is intentional. Distinct normalization forms of the same text must share one key.

codex
- **`Search.kt:3,5` — Submitted keys are never normalized.** `ingress` passes raw text directly to `addCanonical`, which inserts it unchanged. Canonically equivalent inputs such as `"\u00E9"` and `"e\u0301"` therefore occupy separate entries, violating the required deduplication. Require NFC normalization before insertion, preferably enforced by `KeyStore` itself, using `Normalizer.normalize(key, Normalizer.Form.NFC)`. Preserve case.

- **`Search.kt:2` — Public mutable storage bypasses the canonical-key invariant.** `val` prevents reassignment but still lets callers run `store.keys.add(...)` with non-NFC text, bypassing any checks added to the insertion method. Require a private backing set and, if callers need access, a read-only snapshot or unmodifiable view. All insertions must pass through the invariant-enforcing API.

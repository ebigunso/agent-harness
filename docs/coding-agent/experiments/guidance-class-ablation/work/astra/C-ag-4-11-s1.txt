Reviewer notes: C++17. Public contract: caller owns output and may destroy it immediately after parse returns. Input is a complete token; caching last value is newly requested but no borrowing/lifetime contract was added.

codex
- **`parser.cpp:2–4` — The cache borrows caller-owned storage instead of retaining the last parsed value.** `last_output=&output` becomes dangling if the caller destroys `output`, which the public contract explicitly allows; a subsequent `preview()` then has undefined behavior. Even while `output` remains alive, caller modifications change the preview without another parse. Require an internally owned string snapshot, updated on successful parsing, with `preview()` reading that snapshot. This keeps preview additive without imposing a breaking lifetime requirement on callers.

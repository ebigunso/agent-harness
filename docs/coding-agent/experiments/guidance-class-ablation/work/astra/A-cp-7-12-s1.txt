Reviewer notes: Scala 2.13. The cluster harness boots a real localhost cluster server on port 5080; each connection emits current state and next event as two UTF-8 lines. Closed protocol guarantees running/paused state and pause/resume/other event. Existing validation boots that cluster and searches stdout for paused. The reducer has no callable state/event seam.

codex
- **`ClusterReducer.scala:9–16` — Validation does not establish that the pause transition works.** Searching stdout for `paused` also passes for an initially paused state with an `other` event, even if the new transition is missing. The socket-bound implementation provides no direct way to test the transition independently. Require deterministic tests asserting `running + pause → paused`, `paused + resume → running`, and unchanged state for unmatched pairs. Extracting a callable `reduce(state, event)` function would make these tests straightforward.

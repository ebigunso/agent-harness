+import scala.concurrent.{ExecutionContext,Future}
+object Fallback {
+ def read(circuitOpen: Boolean, primary: () => Future[String], mirrors: Vector[() => Future[String]])(implicit ec: ExecutionContext): Future[String] = {
+  if(circuitOpen) Future.firstCompletedOf(mirrors.map(call => call()))

Commit message: "use mirror fallback when circuit is open"

Reviewer notes: Scala 2.13. Three mirrors share the same upstream outage domain. Gateway futures may never complete; no per-call or aggregate deadline. Every request during open circuit fans out; fallback should be bounded degradation.

codex
- **`Fallback.scala:4` — Unbounded fallback fan-out bypasses outage containment.** Every request during an open circuit invokes every mirror, and the three mirrors share the same upstream outage domain. This can amplify load on the failing dependency. Require a bounded fallback policy with concurrency/admission limits and an explicit degraded response when its budget is exhausted; correlated mirrors must respect shared outage protection.

- **`Fallback.scala:4` — The fallback can remain pending forever.** There are no call or aggregate deadlines, and `firstCompletedOf` also never completes for an empty mirror vector in Scala 2.13. Require explicit empty-vector handling and a finite overall deadline, with intentional per-call timeouts and terminal failure/degradation behavior. Timing out the returned future alone does not cancel underlying work; resource limits must account for that.

- **`Fallback.scala:4` — The fastest failure defeats viable mirrors.** `Future.firstCompletedOf` selects the first completion, including failure. A mirror that fails quickly therefore fails the request even if another mirror subsequently succeeds. Require first-success selection within the fallback budget, failing or degrading only when all candidates fail or the deadline expires.

- **`Fallback.scala:4` — A synchronous mirror exception escapes the asynchronous failure path.** `call()` executes eagerly inside `map`. If it throws before returning a future, `read` throws synchronously, later mirrors are skipped, and already-started calls continue without an aggregate result. Require conversion of nonfatal invocation exceptions into failed futures so they participate in the same bounded fallback policy.

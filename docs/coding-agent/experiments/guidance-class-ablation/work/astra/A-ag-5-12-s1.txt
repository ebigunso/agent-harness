Reviewer notes: Scala 2.13, single-threaded store. Capability is valid only while its owner session exists. New cleanup deletes owner but leaves capabilities active; current verifier checks capability record only.

codex
- **`Sessions.scala:6–7` — Expiration leaves the owner’s capabilities valid.** `expire(owner)` removes the owner from `owners`, but `valid(token)` checks only the capability’s `active` flag. Any active token belonging to that owner remains usable after expiration, violating the requirement that capabilities are valid only while their owner session exists. Require validation to check both conditions: `capabilities.get(token).exists(c => c.active && owners.contains(c.owner))`. Add a regression test proving that expiring an owner invalidates their tokens while leaving another owner’s tokens valid.

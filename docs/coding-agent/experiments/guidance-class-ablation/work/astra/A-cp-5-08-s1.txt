Reviewer notes: Transport has parsed an object and validated type is a string. Remote service can send future event types; supported local types are paid and cancelled. These local handlers return acknowledgement strings only.

codex
- **`hook.ts:3–4` — Dispatch does not validate supported event types.** The cast only changes TypeScript’s view; a future event type still makes `handlers[type]` undefined, so calling it throws. Inherited names such as `"toString"` can also resolve to unintended functions. Since remote types can exceed the two supported types, require an explicit `paid`/`cancelled` switch or an own-property check, plus deliberate handling of unsupported events before invoking a handler.

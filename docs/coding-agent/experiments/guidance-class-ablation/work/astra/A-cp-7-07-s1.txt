Reviewer notes: Vendor endpoint is a configured private network sidecar; opening /session creates a billed vendor session. Session disposal and HTTP errors are handled below. The tax branch is pure 10% of nonnegative decimal subtotal for domestic shipments and zero otherwise, but currently requires opening that session. No transport replacement hook exists.

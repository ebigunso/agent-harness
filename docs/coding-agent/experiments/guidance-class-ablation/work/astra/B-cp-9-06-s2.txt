- **`Authorization.cs`, fallback return in `catch (PolicyUnavailable)` — stale cached grants fail open.** The cache never expires, so a previously allowed entry can grant access after revocation whenever the policy service is unavailable. This violates the immediate-revocation contract and the prohibition on offline grants. Require denying access on `PolicyUnavailable` while retaining diagnostic logging. Adding an expiry or checking `FetchedAt` would still permit revoked access within the freshness window and would not satisfy this contract.

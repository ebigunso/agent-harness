- **`src/export.php`, `catch (DiskWriteError)` and final return:** The write failure is logged and swallowed, so the function returns `status: ready` for an incomplete artifact. Consumers then read partial data as a completed export. Require failure propagation or an explicit failure result; return `ready` only after successful completion.

- **`src/export.php`, `openForReplace($destination)`:** Opening the destination truncates the earlier valid export before the replacement succeeds.

Reviewer notes: Scala 2.13. The cluster harness boots a real localhost cluster server on port 5080; each connection emits current state and next event as two UTF-8 lines. Closed protocol guarantees running/paused state and pause/resume/other event. Existing validation boots that cluster and searches stdout for paused. The reducer has no callable state/event seam.

### Gate 6: Operational and Failure Containment

**Expectation**

- Broad exception/error suppression that obscures root causes.
- Cascading failure paths without isolation boundaries.

+object Fallback {
+ def read(circuitOpen: Boolean, primary: () => Future[String], mirrors: Vector[() => Future[String]])(implicit ec: ExecutionContext): Future[String] = {
+  if(circuitOpen) Future.firstCompletedOf(mirrors.map(call => call()))

Reviewer notes: Scala 2.13. Three mirrors share the same upstream outage domain. Gateway futures may never complete; no per-call or aggregate deadline. Every request during open circuit fans out; fallback should be bounded degradation.

codex
- **`Fallback.scala:4` — Unbounded fan-out defeats bounded degradation.** Every request during an open circuit starts all mirrors, and all three share the upstream outage domain. This amplifies outage traffic; returning one result does not stop outstanding calls. Require a bounded fallback policy with concurrency limits and a request/attempt budget, plus a terminal degraded response when that budget is exhausted. Shared-domain mirrors should not be treated as independent recovery paths.

- **`Fallback.scala:4` — Fallback can hang indefinitely.** There are no per-call or aggregate deadlines, and gateway futures may never complete. An empty `mirrors` vector also leaves `firstCompletedOf` pending forever in Scala 2.13. Require explicit empty-set handling, bounded deadlines, and a defined timeout/degradation result. Bound or cancel underlying work where supported so timed-out requests do not accumulate.

- **`Fallback.scala:4` — The first failure defeats potentially successful fallback.** `Future.firstCompletedOf` returns the first completion, including failure. A fast failing mirror therefore fails the request even if another mirror could succeed within the budget. Require bounded success-seeking fallback, with deliberate error propagation when all allowed attempts fail or the deadline expires.

- **`Fallback.scala:4` — Synchronous mirror exceptions escape containment.** `call()` executes directly during `map`; if it throws before returning a future, `read` throws synchronously, skips subsequent mirrors, and leaves previously started calls running. Require converting nonfatal invocation exceptions into failed attempt futures and handling them through the same bounded fallback policy.

Reviewer notes: Scala 2.13. Three mirrors share the same upstream outage domain. Gateway futures may never complete; no per-call or aggregate deadline. Every request during open circuit fans out; fallback should be bounded degradation.

codex
- **`Fallback.scala:4` — Unbounded waiting.** `firstCompletedOf` never completes if all mirror futures hang; an empty mirror vector also never completes. With no deadlines, requests can accumulate indefinitely during an outage. Require an aggregate fallback deadline and an explicit failure for no mirrors. Bound underlying calls where supported; timing out the returned future alone does not stop them.

- **`Fallback.scala:4` — Every request eagerly invokes every mirror.** `mirrors.map(call => call())` starts all calls before selecting a result. Because the mirrors share an outage domain, this multiplies traffic against the failing upstream, and repeated requests can accumulate unlimited outstanding calls. Require bounded attempts and shared concurrency/admission limits, with prompt degradation when capacity is exhausted.

- **`Fallback.scala:4` — The first failure wins over potentially successful mirrors.** `firstCompletedOf` selects the first completion, including a failed future. One fast failure therefore fails the request even if another started mirror subsequently succeeds. Require success-aware fallback within the attempt and time budgets, failing when those budgets expire or the allowed attempts are exhausted.

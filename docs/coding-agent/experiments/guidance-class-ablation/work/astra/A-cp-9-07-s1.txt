- **`worker/start.go`, `supervisor.Succeeded(job.ID())` and unread `result` channel:** The function records durable success immediately after launching the goroutine, before `job.Run` finishes, and always returns `nil`. Any eventual error is stranded in the channel. This falsely marks running or failed jobs as successfully completed and makes failures unobservable. Require completion handling that calls `Succeeded` only after `Run` returns `nil` and exposes errors through an observable asynchronous completion mechanism, such as a returned result channel or supervisor failure reporting.

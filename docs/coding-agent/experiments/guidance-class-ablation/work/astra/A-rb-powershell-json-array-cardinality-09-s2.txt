codex
**Cause:** This is a script bug in the workspace. In Windows PowerShell 5.1, `ConvertFrom-Json` preserves the JSON array, but the following `Write-Output` enumerates it. Assignment then stores the sole element as `System.Boolean`, causing the assertion to fail. The JSON is valid.

**Smallest safe remediation:** Remove the trailing `| Write-Output`:

```powershell
$raw = Get-Content -Raw data.json
$parsed = $raw | ConvertFrom-Json
```

Do not simply wrap the pipeline in `@(...)`: that would also turn scalar JSON values into arrays, violating the contract.

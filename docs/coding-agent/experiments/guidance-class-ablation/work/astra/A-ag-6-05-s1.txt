Commit message: "retry uncertain object uploads"

Reviewer notes: C# storage client honors timeout/cancellation internally and throws TimeoutException on unknown outcome. Create is idempotent only for a stable key. Retry is bounded at three; fresh key after unknown success creates extra stored objects.

codex
- **Upload.cs:7 — Retries generate a new object key.** A timeout can mean the previous upload succeeded but its response was lost. Retrying with a fresh key can therefore create duplicate stored objects, because `Create` is idempotent only for a stable key. Generate the key once before the retry loop and reuse it for all three attempts.

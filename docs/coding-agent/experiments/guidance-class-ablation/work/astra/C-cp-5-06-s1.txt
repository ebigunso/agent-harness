Reviewer notes: C# decimal. Money represents a nonnegative debit magnitude; overdraft is permitted by account policy, so balance bounds are separate. Public constructor is callable by import and API adapters.

codex
- **`Money.cs:4` — Public constructor bypasses the nonnegative invariant.** `new Money(-10m)` succeeds even though `Money.Create(-10m)` rejects it. Import and API adapters can therefore create invalid debit amounts, causing `Ledger.Debit(100m, new Money(-10m))` to increase the balance to `110m`. Require validation in the public constructor, throwing `ArgumentOutOfRangeException(nameof(amount))` for negative values, and have `Create` delegate to it. Negative resulting balances remain permitted under the stated overdraft policy.

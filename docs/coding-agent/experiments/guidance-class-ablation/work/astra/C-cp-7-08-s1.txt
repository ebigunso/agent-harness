codex
- **`test_limit.rb:4–16` — Parallel tests share and mutate process-wide `ENV`.** `CustomLimitTest#setup` sets `LIMIT=2` without restoring it, while `DefaultLimitTest` assumes the variable is absent. The default test can therefore fail depending on execution order or the inherited environment, and the mutation leaks into other tests. Require a deterministic seam for supplying the limit or configuration, with isolated default and custom-limit tests. Restoring `ENV` in teardown alone would not fix concurrent interference; any tests exercising actual environment lookup must also isolate that access, such as in separate subprocesses.

Commit message: "retry uncertain object uploads"

Reviewer notes: C# storage client honors timeout/cancellation internally and throws TimeoutException on unknown outcome. Create is idempotent only for a stable key. Retry is bounded at three; fresh key after unknown success creates extra stored objects.

codex
- **Upload.cs:7 — Retries use a new object key.** A timeout may mean the upload succeeded but its acknowledgement was lost. Retrying with a fresh GUID creates another stored object, defeating `Create`’s idempotency and potentially leaving duplicates. Generate the key once before the retry loop and reuse it for every attempt. Require a test where the first call stores the object and then throws `TimeoutException`, verifying that retries use the same key and leave only one object.

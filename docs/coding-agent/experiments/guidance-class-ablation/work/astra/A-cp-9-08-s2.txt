- **`lib/customers.rb`, `find_customer` — rescuing `DatabaseUnavailable` as `nil` violates the lookup contract.** `nil` means genuinely absent, so `get_or_create` treats an outage as permission to create. With the write primary available, this can attempt to recreate an existing customer, causing duplicates or a uniqueness failure even with serialized calls. Require an explicit repository-level unavailable error or distinct failure result, and ensure `get_or_create` only creates after a confirmed not-found result.

The cause is **pipeline enumeration, not a workspace problem**. `-NoEnumerate` preserves the JSON array initially, but the subsequent `ForEach-Object` pipeline enumerates it. With one element, assignment produces a `PSCustomObject`, so the assertion throws.

The smallest safe remediation is to remove that extra pipeline:

```powershell
$parsed = $raw | ConvertFrom-Json -NoEnumerate
```

Keep the existing assertion:

```powershell
if ($parsed -isnot [array]) { throw 'Expected JSON array' }
```

+require "active_record"
+class Inventory < ActiveRecord::Base
+end
+def normal_update(item, delta)
+  item.with_lock do
+    value = item.quantity + delta
+    raise ArgumentError, "negative quantity" if value < 0
+    item.update!(quantity: value)
+  end
+end
+def admin_update(item, delta)
+  item.with_lock { item.update!(quantity: item.quantity + delta) }
+end

Reviewer notes: Rails 7. Quantity must never become negative. Normal path guards under row lock; new admin path writes directly. Database has no CHECK constraint and model has no numericality validator. Both amounts are parsed integers.

codex
- **`inventory.rb:12` — Admin adjustments can make quantity negative.** `admin_update` writes `item.quantity + delta` without checking the result. For example, quantity `2` with delta `-3` persists `-1`; neither the model nor database rejects it. The row lock prevents concurrent update races but does not enforce the nonnegative invariant. Require enforcement at a shared persistence boundary—preferably a database `CHECK (quantity >= 0)`, with model validation for friendly errors—and retain the lock. Verify that both normal and admin adjustments reject negative results while allowing zero.

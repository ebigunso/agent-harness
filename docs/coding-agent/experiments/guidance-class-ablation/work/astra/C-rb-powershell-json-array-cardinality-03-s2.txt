codex
The failure is in the checker, **not the workspace**. `ConvertFrom-Json` enumerates the JSON array by default, so assigning its single emitted element produces a `System.String`. The assertion mistakes that for scalar wire input.

On PowerShell 7.4.6, the smallest safe fix is to replace the parse line with:

```powershell
$parsed = ConvertFrom-Json -InputObject $raw -NoEnumerate
```

Keep the existing assertion:

```powershell
if ($parsed -isnot [array]) { throw 'Expected JSON array' }
```

Direct assignment preserves the array; do not pipe the parsed output through another command. Merely wrapping the original parse in `@(...)` would also wrap scalar inputs and incorrectly accept them.

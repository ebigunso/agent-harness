Task framing: Retry uncertain object uploads.

```diff
--- a/Upload.cs
+++ b/Upload.cs
@@ -0,0 +1,11 @@
+using System;
+using System.Threading.Tasks;
+public interface IStorage { Task Create(string key, byte[] data); }
+public static class Upload {
+ public static async Task Send(IStorage storage,byte[] data) {
+  for(int attempt=0;attempt<3;attempt++) {
+   try { await storage.Create(Guid.NewGuid().ToString(),data); return; }
+   catch(TimeoutException) when(attempt<2) {}
+  }
+ }
+}
```
Commit message: "retry uncertain object uploads"

Reviewer notes: C# storage client honors timeout/cancellation internally and throws TimeoutException on unknown outcome. Create is idempotent only for a stable key. Retry is bounded at three; fresh key after unknown success creates extra stored objects.

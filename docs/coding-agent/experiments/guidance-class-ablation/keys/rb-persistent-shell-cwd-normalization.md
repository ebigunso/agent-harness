## Shared diagnosis and confirmation requirements

Common hit: identify pre-normalization cwd and intended cwd, inspect state before changing it, make one explicit navigation to the intended path, rerun the **original command unchanged**, and record exit 0 plus appropriate successful output and final cwd. Fixture 1 normalizes to parent root before repeating its original cd chain; most other fixtures normalize directly to execution root. No reinstall, file copying, config rewrite, or repeated nested cd. If retry still fails, do not keep insisting cwd was the whole cause.

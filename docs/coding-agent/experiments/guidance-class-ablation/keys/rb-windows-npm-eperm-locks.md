## Shared diagnosis and confirmation requirements

All hits must identify the locked native addon and its holder, stop the identified repo process gracefully first, use a confirmed PID-specific termination only as last resort, then rerun the original install. Do not kill every Node process or delete lockfiles. Confirmation: install exit 0 and no repeated lock error; record original error, module, holder/PID, any termination, retry result. Distinct scenario coverage concerns holder lifetime/process scope, not separate mechanisms.

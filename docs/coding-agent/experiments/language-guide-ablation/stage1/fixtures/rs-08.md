Task framing: Parse the batch size from the job spec when starting a worker.

```diff
--- a/src/worker/spawn.rs
+++ b/src/worker/spawn.rs
@@ pub fn spawn_worker(spec: &JobSpec) -> WorkerHandle {
-    let batch = spec.batch_size().unwrap_or(DEFAULT_BATCH);
+    let batch: usize = spec
+        .raw
+        .get("batch_size")
+        .expect("job spec missing batch_size")
+        .parse()
+        .expect("batch_size must be an integer");
     WorkerHandle::start(batch)
 }
```
Note: `spec.raw` is deserialized from operator-supplied YAML at runtime; `spawn_worker` runs in the scheduler's main loop.

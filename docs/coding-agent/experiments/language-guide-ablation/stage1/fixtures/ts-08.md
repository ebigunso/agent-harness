Task framing: Add tier-upgrade eligibility to the subscriptions service.

```diff
--- a/src/domain/subscriptions.ts
+++ b/src/domain/subscriptions.ts
@@ export class SubscriptionService {
+  async canUpgrade(subId: string, res: Response): Promise<void> {
+    const sub = await this.repo.get(subId);
+    if (!sub) {
+      res.status(404).json({ error: "not found" });
+      return;
+    }
+    const eligible = sub.state === "active" && sub.paymentFailures === 0;
+    res.setHeader("Cache-Control", "no-store");
+    res.status(200).json({ eligible });
+  }
 }
```
Note: `SubscriptionService` is the domain layer; routes live in `src/http/` and call into it.

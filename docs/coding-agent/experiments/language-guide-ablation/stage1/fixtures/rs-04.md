Task framing: Add transfer between wallets to the payments module.

```diff
--- a/src/payments/transfer.rs
+++ b/src/payments/transfer.rs
@@
+pub fn transfer(
+    ledger: &mut Ledger,
+    from: String,
+    to: String,
+    amount: String,
+    currency: String,
+) -> Result<String, TransferError> {
+    let amt: i64 = amount.parse().map_err(|_| TransferError::BadAmount)?;
+    ledger.debit(&from, amt, &currency)?;
+    ledger.credit(&to, amt, &currency)?;
+    Ok(format!("tx-{}-{}", from, to))
+}
```
Note: the crate already defines `WalletId`, `Money`, and `TxId` types used by the ledger internals.

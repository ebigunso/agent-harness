Task framing: Add an endpoint for support staff to look up an order by id.

```diff
--- a/server/routes/support.py
+++ b/server/routes/support.py
@@
+@app.get("/support/orders/<order_id>")
+def get_order(order_id):
+    user = require_login()
+    if not user.has_role("support"):
+        abort(403)
+    order = db.query_one("SELECT id, status, total FROM orders WHERE id = %s", order_id)
+    if order is None:
+        abort(404)
+    return jsonify(order)
```

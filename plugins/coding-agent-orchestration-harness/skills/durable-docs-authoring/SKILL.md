# Skill: durable-docs-authoring

This skill prevents recurring structural defects in durable documentation: ambiguous terminology, mixed abstraction levels, stale time-relative language, flat emphasis, and misleading names.

---

## Progressive disclosure

When this skill triggers, read the authoring rules and pre-finalization check before drafting or restructuring:
- Read references/authoring-rules.md

When deciding whether a decision meets the admission test for a decision record (ADR), proposing or drafting one, retiring or replacing one, or presenting one for acceptance: read references/adr.md. Run its admission test on every proposed record, including one a plan or an older record told you to write.
